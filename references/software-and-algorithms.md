# 程序、依赖和算法

## 程序分工

| 程序/组件 | 用途 | 是否访问真实 EDA |
|---|---|---|
| Codex 或其他 Agent | 理解功能、制定模板、修改无解候选、审查图面 | 通过另行配置的工具 |
| Python 3.10+ | 模型变换、标签搜索、装箱、图论/几何校验和报告 | 本包 Python CLI 不访问 |
| lxml | 读取、保留与输出 SVG/XML 元件图形 | 否 |
| Node.js + Playwright | 启动本地浏览器测量文字、截图、检查预览 | 否，不连接用户浏览器会话 |
| Chrome / Edge / Chromium | 执行 SVG `getBBox()` 和坐标变换；实际字体排版 | 否，测量时离线 |
| HTML + SVG | 可切页、缩放的离线预览 | 否 |
| easyeda-agent CLI / daemon / EDA Agent Connector | 将真实编辑器读写请求传给官方 `eda.*` 接口 | 是，独立安装 |
| 嘉立创 EDA | 原生元件、导线、属性、保存重载和原生 DRC | 是 |
| unittest、SHA-256、ZIP | 回归/故障测试、文件完整性、可分享交付 | 否 |

`design-hardware` 提供硬件协作方法，`easyeda-agent` 提供现场执行流程；本 skill 组织排版算法与校验。skill 本身不会授予本机或 EDA 访问能力。

## 实际使用的算法

### 1. 功能模板与绘图语法

文件：`scripts/layout_engine/drawing.py`、`pipeline.py`。

Agent 先按功能决定芯片、外围、阅读顺序与物理直连，再将位置、允许旋转、短线和正交路径写入 manifest。模板选择依靠电路知识与用户风格，程序不会仅凭网表推断正确外围归属。所有引脚坐标取自真实导入；变换保持相对位置与符号一致。

示例由 `scripts/layout_engine/demo.py` 从零合成，使用通用矩形符号和虚构的引脚契约，不对应真实产品。接收者根据自己的数据创建模板，分享包不携带任何实际产品的器件选型、位号映射、网表或布局。

### 2. 实际文字边界测量

文件：`scripts/browser_svg.cjs`、`model.py`。

浏览器加载原生 SVG，对可见文字执行 `getBBox()`，用 CTM 矩阵转换到原生 raw 坐标，再把屏幕 Y 方向转换为 Y-up。原位号/参数保留原图样式；新增网名使用 Arial、7.0062 raw、原生标签的 ideographic 基线；模块标题单独以 12 raw 测量。

这解决“字数相同但字宽不同”和“GND 不是零面积点”的问题。字体替代、SDK 基线或符号变化仍需实际回读核对。`getBBox()` 是包围盒，不是逐像素墨迹轮廓，避让采取较保守边界。

### 3. 位号与参数的有限候选搜索

文件：`labels.py`。

为每个可移动文字枚举主体上方、下方、左右等候选；固定内部文字保留。先排核心位号与长文字，拒绝碰到器件、文字、引脚杆或导线的位置，再选位移代价较小的位置。模板提供的风格候选按优先级排列。

这是确定性贪心搜索，不能保证全局最优；无合法候选就报告失败，回到模板扩大间距或调整标题行。

### 4. 网络标签避让

文件：`net_labels.py`。

先按实际导线段建立同网物理岛，长网名优先。仅在所属物理岛上搜索水平/垂直标签锚点，可按 5 raw 步长小幅延长导线。硬约束包括文字/器件重叠、穿越其他线与引脚、跨网接触和越过模块框。

可行位置以偏离原位置、锚点位移和延长量打分；垂直线候选带附加代价。仅允许标签与其所属物理岛的正常原生基线接触，不能豁免其他网络。

### 5. 接地标志与短线方向

文件：`drawing.py` 中 `fit_native_grounds()`，以及 `pin_exit.py`。

接地搜索枚举四个方向、短距离延长和少量 L 形绕行，使用实际 GND 图形与文字障碍，优先短路径、少交叉。

`calibrate_ground_label()` 从至少两个未修改的原生 SVG 标签推导零度接地文字相对边界，检查样式一致、本体几何与字号。提供校准 profile 时仅搜索已验证的零度方向，不从一个朝向推断其他朝向。默认模型与工程实际样式不同时，独立 SVG 检查会拒绝，必须先校准并重新生成候选。

`bad_pin_exits()` 检查每根接触引脚的导线，必须先沿该引脚向外方向延伸。`shifted_bus()` 只处理同向垂直引脚与水平总线：把总线外移并补短引线，再完整复查。它不处理所有任意走线错误。

### 6. 功能模块矩形装箱

文件：`packing.py`、`pipeline.py`。

模块内部通过检查后，整体作为矩形移动。算法保留空闲矩形集合，用 best-short-side-fit 选择落点；放置后分割空闲矩形并剔除被包含区域，类似 MaxRects。尝试语义顺序、高度排序、面积排序及多种页面宽度。

当前评分：

```text
score = usedWidth × usedHeight + abs(usedWidth - usedHeight) × aspectPenalty
```

默认 `aspectPenalty=50`，同分时倾向较小高度/宽度。模块不随意旋转；重复阵列可在功能模板中先生成，再整体装箱。该算法优化占用面积，不代表达到全局最紧凑解，也不自动改变用户确定的页归属。

### 7. 图论连通与独立几何检查

文件：`validator.py`、`native_verify.py`。

使用并查集（DSU）按端点、T 接触和同轴重叠合并导线段。普通内部 X 交叉默认不连接，明确结点或同一原生线对象按其契约处理。检查 NC、错网、异网端点接触、孤立标签和必需的物理直连引脚对。

原生回读检查不信任计划里给导线标的网名，而是从**实际引脚 + 实际可见 Name 属性 + 实际 GND 标志**重建连通分量并推导网络。再把线段按网络/方向/轴位置归并成区间，双向比较覆盖：允许 SDK 拆分或合并线段，不允许少线、额外线或网名被改。

几何检查还覆盖文字与文字/器件/导线、导线与器件/异网引脚杆、器件包围盒相交和向外引线。多数相交检查是成对比较，复杂度接近 O(n²)，当前适合模块化普通原理图；大规模图可进一步增加空间索引。

## 没有被夸大的能力

- 本包以功能模板、局部几何搜索和装箱为主，不含通用全图 A* 路由器。
- 通过网表并不自动推导模拟稳定性、时序、供电能力或器件绝对额定值。
- 不含训练模型、商业排版求解器、GPU 训练或神经网络风格学习。
- 可以减少 Agent 逐坐标试错，但没有完成 token 节省比例或通用排版质量的对照实验。
- 离线测量、真实回读、原生 DRC、保存重载与实物验证是不同证据层级。
