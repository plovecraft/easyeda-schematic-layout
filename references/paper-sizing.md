# 纸张尺寸与标题栏

先得到紧凑模块，再比较可用纸张。不要固定最大纸张后只占一个角，也不要固定 A4 或用缩小字号来塞图。沿用用户指定纸张；未指定时选能容纳当前功能分页、正常字号和必要间距的较小尺寸。页内功能关系优先，不为填满纸张拉长导线或放大模块间距。

## 真实边界

纸张轮廓、内边框、图签和其他禁布区域从当前原生图框与 SVG 实测获得，坐标为 raw / Y-up。模板比例推算必须标为近似，不能冒充实际边界。不同纸张的图签不一定同比例缩放；不能只把纸张长宽乘系数就推导标题栏。

当前工具可通过库里的 Drawing-Symbol 图框符号新建图纸；切换既有图框时先备份，并核对当前 CLI 对 sheet 删除/新建的支持。不要把 titleblock 的 Width / Height / Size 等结构字段当作换纸接口。超时先回读 sheet 数量与身份，不能重复创建多个图框。

对比排版时保留器件、引脚、网名和字号。page 的 `titleFontSize` 可指定原有功能标题字号，标题必须按这个字号重新实测，程序相应预留标题带；不能靠把标题改小取得面积优势。

## 可选的有限纸张比较

`layout.json` 的每个 page 可加入 `papers`；未提供时保留旧的自由画布装箱。每个候选来自已确认的几何，不内置未经测量的 A 系列数值。

```json
{
  "id": "1",
  "title": "Control",
  "widths": [700, 900, 1100],
  "papers": [
    {
      "id": "measured-paper-a",
      "paperBBox": {"minX": 0, "minY": 0, "maxX": 1170, "maxY": 825},
      "usableBounds": {"minX": 25, "minY": 220, "maxX": 1145, "maxY": 800},
      "keepouts": [{"minX": 468, "minY": 0, "maxX": 1170, "maxY": 198}],
      "source": "example values only; replace with this editor's measured native geometry"
    }
  ]
}
```

这是字段示例，数值不能直接当作任意环境的标准。`usableBounds` 是保守的矩形可用区域，通常扣去内边框净距及整条图签带；`keepouts` 保留实际禁布矩形。没有一般多边形/不规则剩余区域装箱能力。若要利用图签左侧空位，应先建立受测量支持的分区模板，不绕过碰撞检查。

程序按可用宽高重新装箱，把器件、文字、线段、模块框与标题一起平移，整体尽量居中于扣除标题栏的可用矩形；中心位置按 5 raw 网格取最近合法点，单轴误差最多 2.5 raw，不拉散模块内部；对整页重新运行电气与版面校验，并检查模块包络与所有 keepouts。通过后选纸张面积最小的候选，同面积再比内容面积与输入顺序。`paper-selection.json` 留存成功、失败和选中项。所有纸张都放不下时明确失败；先调整功能布局，再考虑较大纸张或用户允许的分页，不静默缩字。

`paperless:false` 仅表示离线候选使用了输入的纸张几何，仍不证明已写入 EDA。实际创建/替换图框后要回读真实纸张、标题字段与整页 SVG，验证实际导图，必要时重新选纸。不强求所有页面相同尺寸，也不以占用率达到某个固定百分比作为合格标准。
