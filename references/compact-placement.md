# 紧凑摆放与减少折返

目标是让元件、引线、全部可见文字与功能分组共同占用较小空间，同时保持清晰。电容、电阻、二极管等元件没有通用的横放/竖放优先级；朝向由真实引脚、连接关系、文字边界与周围空间决定。

## 制定候选的顺序

1. 保留原布局作为 `base` 候选。确定功能归属、必需物理直连和阅读顺序，再选允许改变位置/朝向的元件。带内部文字、多单元或未校准的符号不能套用双引脚旋转逻辑。
2. 优先对齐连接轴线：串联元件的相接引脚、芯片引脚与支路汇合点、重复滤波支路的主线。移动元件或调整合法朝向消除台阶，比在固定位置间增加绕线优先。
3. 引脚先沿自身方向向外引出，再分支或转弯。并联元件的引脚端点不要直接横接总线；可略移元件，让短引线到达已有主线，避免为整根主线额外抬高一档。
4. 对小范围位置、允许朝向和直线/L 形路径生成有限方案，每种姿态使用变换后的真实引脚及实测文字。路径先试直接连接，再试必要转弯；检查通过前不能把最短线当作正确线。
5. 接地尽量就近，短引线仍需非零、方向正确，符号和网名有实际占位。共用回线与本地符号均可按电气意图选择；不能用标签替代已要求的外围物理直连。
6. 以模块完整可见包络比较面积、折点、线长和交叉；随后整体装箱并再查整页。不要只缩功能框、隐藏参数或减小字号来降低面积。重复通道宜保持方向、列距与阅读顺序一致。

这是一组候选生成规则，由 Agent 建立模板；程序不会只凭网表自动推导全部元件姿态或路径。

## 可执行的候选比较

在模块上添加 `variants`。原模块保持为 `base`，额外候选最多 63 个；每个候选先经过完整文字、器件、引脚方向、NC、短接、网络作用域和物理直连检查。

允许候选修改的字段：

| 字段 | 行为 |
|---|---|
| `id` | 唯一的安全目录名，不能用保留名 `base` |
| `positions` / `rotations` | 合并指定元件的目标 anchor / 已支持的四分之一转；不能加入或移除元件 |
| `wires` / `stubs` / `markers` | 整份列表替换；移动元件后需更新路径或使用随引脚求值的端点 |
| `captionOptions` | 合并本候选的文字布局偏好 |

候选不能改 `scopes`、`requiredPhysicalPairs`、源器件身份、参数、目标网表或校验例外；电气修改应先单独建立明确的目标源。

对原有合成 demo 的第一个模块，可添加以下内容；其中旋转数字只对应这个虚构符号，不是实物电容的规定朝向：

```json
{
  "variants": [{
    "id": "alternative",
    "positions": {"C1": [-80, 90]},
    "rotations": {"C1": 270},
    "wires": [{"net":"3V3", "points":[["U1","3"],[0,90],["C1","1"]]}],
    "markers": [{"id":"supply1", "kind":"label", "net":"3V3", "point":[-40,90]}]
  }],
  "objective": {"area":1, "bends":400, "wireLength":2, "crossings":5000}
}
```

`["ref","pin"]` 和 `{ "pin":["ref","pin"], "offset":[dx,dy] }` 端点按该候选的真实引脚求值。其他显式数值拐点不会跟着元件自动移动。

默认评分（raw 坐标）为：

```text
score = area + 400 × bends + 2 × wireLength + 5000 × crossings
```

全部硬约束先通过，分数才有意义。`objective` 可调四项权重：面积权重必须为正，其余非负，均需有限。面积使用器件、文字、接地及导线的完整包络；交叉是几何指标，不能以惩罚分接受实际短接。相同分数按面积、折点、线长及输入顺序稳定决胜，没有元件类型或横竖朝向加分。

每个模块输出 `selection.json`，记录所有候选的指标、评分、拒绝原因与选中项；`variants/候选ID/` 保留检查报告和可生成的候选图。所有候选失败时保存失败记录并非零退出，不选“错误最少”的方案。源模型、测量和模板输入保持不变。

## 合成试验

```powershell
python scripts/layout.py demo --compare-placements --out ./placement-demo
python scripts/layout.py check-preview --input ./placement-demo/result/preview.html --out ./placement-demo/preview-check.json
```

打开预览并检查 `result/modules/*/selection.json`。示例覆盖不同朝向胜出和非法重叠被拒绝，全部由虚构符号生成，不访问 EDA 或用户工程。

## 实际能力边界

这是有限模板比较加模块装箱：程序在**提供的候选中**取最小评分，不保证任意电路的全局最小面积，也不穷举所有模块姿态组合。模块内最紧凑与整页最紧凑可能不同；必要时由 Agent 调整候选、页面宽度或长宽比，再重算整页。原生保存重载、DRC 与硬件验证仍需分别完成。
